## About

**VOID** is an atmospheric horror game currently in development by **Necron Studios**, an independent game development studio focused on creating original games and immersive worlds.

The game takes place on the **Island of the Void**, a mysterious island hiding the remains of a catastrophic scientific incident and a secret underground research facility.

VOID focuses on **horror, exploration, survival and atmosphere**, with an emphasis on vulnerability and immersion rather than conventional combat.
