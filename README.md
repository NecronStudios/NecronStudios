# Necron Studios — Official Website

A static, multi-page website for Necron Studios.

## Structure

- `index.html` — homepage
- `studio.html` — studio page
- `void.html` — VOID project page
- `contact.html` — contact page
- `style.css` — all visual styling
- `script.js` — navigation, scroll reveal, cursor and progress bar
- `assets/` — SVG marks used by the site

## GitHub Pages

Keep the HTML files in the repository root. For a GitHub Pages branch deployment, use:

- Branch: `main`
- Folder: `/ (root)`

The homepage must remain named `index.html`.

## Important

The included `assets/necron-mark.svg` is a placeholder monogram. Replace it with the official Necron Studios logo when you have the final asset.

There is no backend in this version. The contact page uses a `mailto:` link.
